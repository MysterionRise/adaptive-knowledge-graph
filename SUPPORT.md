# Getting help

Adaptive Knowledge Graph is maintained in spare time, so support is best
effort. These are the fastest ways to get an answer.

## Before you ask

1. Run `make doctor`. It checks your local environment (toolchain, Docker
   services, Ollama and the model) and reports what is missing.
2. Read the [Quickstart](README.md#quickstart) and
   [Troubleshooting](README.md#troubleshooting) sections of the README.
3. Search [existing issues](https://github.com/MysterionRise/adaptive-knowledge-graph/issues?q=is%3Aissue)
   and [discussions](https://github.com/MysterionRise/adaptive-knowledge-graph/discussions).

## Where to go

| You want to... | Go to |
| --- | --- |
| Ask a question or get setup help | [Discussions: Q&A](https://github.com/MysterionRise/adaptive-knowledge-graph/discussions/categories/q-a) |
| Suggest or discuss an idea | [Discussions: Ideas](https://github.com/MysterionRise/adaptive-knowledge-graph/discussions/categories/ideas) |
| Report a bug | [Bug report](https://github.com/MysterionRise/adaptive-knowledge-graph/issues/new?template=bug_report.yml) |
| Request a feature | [Feature request](https://github.com/MysterionRise/adaptive-knowledge-graph/issues/new?template=feature_request.yml) |
| Report a documentation problem | [Documentation issue](https://github.com/MysterionRise/adaptive-knowledge-graph/issues/new?template=documentation.yml) |
| Report a security vulnerability | Privately, as described in [SECURITY.md](SECURITY.md). Never in a public issue. |

When you open a bug report, include the `make doctor` output, your OS and
hardware (CPU/GPU, RAM), and the exact commands you ran. Remove API keys,
passwords and personal data from logs before you paste them.
